    Start with your orders export
    Use CSV or Excel (.xlsx), up to 2 MB and 10,000 orders. Put column names in the first row and one complete order in each row. Combine product line items first. Formula cells need to be exported as values.

    Tell QueryLens what each column means
    Order date and order amount are required. Leave other fields unused when they are absent. Customer names need a stable customer ID; names alone are not treated as unique people.
    
            
    
            
    
            
    How should each status be counted?
    Paid or refunded orders usually count as completed. Cancelled orders contribute zero revenue. Decide how your export's statuses should be treated.
